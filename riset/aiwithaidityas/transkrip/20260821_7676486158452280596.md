## Transkrip (otomatis, Whisper)

Vibe Quaring Test tahu gak bedanya caching di sebuah sistem dan caching di LLM? Gak tau, gak apa-apa, sini gue jelasin. Belajar AI Engineer Episode 6 supaya kamu gak cuma jadi master prompting. Caching di LLM biasanya disebut dengan KV Caching atau Key Value Caching. Nah, kalau caching yang sering kita tahu kan, kita menyimpan query sebagai key dan kemudian result sebagai value. Tapi kalau di LLM, cachingnya itu berdasarkan token. Dan failure disimpan adalah hasil komputasi dari sebuah token. Kita ambil contoh aja, misalnya kita ngaprom Hello World tanpa KV Caching prosesnya seperti ini. Ketika Hello masuk dilakukan satu komputasi. Hello World dilakukan dua komputasi, sekarang sudah 3 komputasi. Hello World dan Deseru dilakukan lagi 3 komputasi dari awal. Sehingga sekarang totalnya ada 6 komputasi. Nah, sedangkan dengan caching, komputasi dari setiap token itu disimpan ke dalam bentuk Key Value. Yang kemudian digunakan untuk token berikutnya. Jadi kalau misalnya kita lakuin Hello World dan Deseru, akan dilakukan hanya 3 komputasi. Dan kemudian akan melakukan KV Caching lagi untuk token baru berikutnya. Jadi yang perlu kamu tahu, ketika kamu mengirim prom ke sebuah LLM, LLM tidak membaca keseluruhan prom tapi membacanya token per token. Dan terjadi proses komputasi untuk menghasilkan sebuah output. Jadi jangan cuma tahu ngaprom doang, follow supaya episode selanjutnya muncul di FBPcom.
