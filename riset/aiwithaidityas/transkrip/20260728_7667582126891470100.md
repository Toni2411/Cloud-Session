Jangan cuma vape coding tapi juga tahu yang namanya jenis-jenis background jobs. Belajar season design editor 5 supaya kamu naik level dari vape coder jadi real software engineer. Background jobs adalah tugas yang dilakukan di balik layar tanpa interaksi user. Biasanya disebut dengan fire and forget operations. Jadi user ngetrigger dan kemudian dilupakan aja. Habis itu bisa akses alaman lainnya. Pendekatan ini biasanya digunakan untuk mengurangi beban di application UI, meningkatkan availability dan mengurangi interactive response time. Ada dua cara untuk ngetrigger background jobs yang pertama event driven trigger yaitu jobs yang berjalan akibat sebuah event trigger. Bisa jadi dari application UI seperti user click atau submit. Bisa juga diterigir di event dari job line. Atau mungkin perubahan data atau state di application UI ataupun di database. Yang kedua ada schedule driven jobs yaitu jobs yang berjalan berdasarkan schedule yang sudah ditetapkan. Misalnya rutinitas harian untuk memproses data di hari tersebut. Jadi misalnya di set schedule untuk jam 12 malam memproses data user di hari tersebut. Yang sengaja di jalanin jam 12 malam karena keadaan server lagi sepi dan kemudian job ini berjalan di background. Atau bisa juga schedule untuk menghapus data setiap 30 hari.
