Banyak banget anak jurusan IT yang nggak ngerti konsep client dan server-side. Sini gue jelasin, gampang banget. Jadi anggap aja ini adalah sebuah restoran dimana dapur ini adalah sebuah server dan mejamakan adalah clientnya. Jadi dapur akan melayani mejamakan dan mejamakan akan melakukan request ke dapur. Apapun yang terjadi di mejamakan, si dapur nggak akan tahu. Kecuali si mejamakan ngirim sesuatu ke dapur. Oke, kita langsung ke contohnya aja. Jadi di sini aku udah di browser. Browser itu beraksi sebagai sebuah client. Dan nanti kita akan mengirim request ke server dan juga kita akan melakukan sesuatu di client-side. Kalau kita melakukan sesuatu ke server, kita mengirim sebuah request dan di sini bertambah. Kalau kita klik yang client-side, itu tidak akan ada request baru yang dibuat. Semuanya itu terjadi di sisi client. Dan kalau kita refresh, server-side akan tetap 4. Tetapi di client-side itu 0 karena server nggak tahu sama sekali apa yang terjadi di sisi client.
