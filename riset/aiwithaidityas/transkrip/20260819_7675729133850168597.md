## Transkrip (otomatis, Whisper)

Fade coding selalu pakai super base. Oke sih, cuman kamu tetep harus tahu jenis-jenis database lainnya dengan kekurangan dan kelebihannya. Belajar sistem desain episode 11 supaya nanti kalau kamu interview bisa jawab dengan lancar. Pertama ada database yang paling sering digunakan, yaitu relational database. Yaitu database yang menyimpan data dalam bentuk table dengan skema dan juga relasi yang terstruktur. Dan relasinya biasanya dihubungkan dengan primary key dan foreign key. Kelebihannya jelas, struktur datanya terbentuk dengan sangat jelas. Ada dua arsitektur relational database, klien server seperti PostgreSQL, MySQL dan SQL Server. Dan juga ada yang embedded seperti SQL Lite. Jenis kedua yaitu NoSQL. Sedarhananya semua data yang tidak mengikuti SQL atau standard query language. Jadi NoSQL ini query-nya cukup aneh-aneh dan bentuknya juga aneh-aneh. Salah satunya yaitu Document Database yang biasanya paling terkenal adalah MongoDB. Document Database digunakan kalau misalnya kamu butuh skemanya yang flexible. Dan juga butuh untuk nested complex data. Kekurangannya jelas karena skemanya flexible. Relasi antar data bisa terlihat cukup aneh. Dan duplicasi data itu hal yang biasa. Selain itu ada grab database bentuknya seperti titik-titik yang saling berhubungan. Grab database bagus banget kalau kamu butuh yang flexible. Tapi juga butuh untuk menyimpan data yang relasinya banyak banget. Many to many yang sangat complex. Kekurangannya adalah kalau dipakai untuk aplikasi yang cuma create read update delete. Ini sangat tidak efisien. Kecuali kalau crootnya complex. Nah itu adalah dua jenis database komen di bawah kalau ada yang ketinggalan. Sekarang kamu tahu nggak supa base itu masuk kemana. Jangan cuma vibe coding terus setuju semuanya ya.
